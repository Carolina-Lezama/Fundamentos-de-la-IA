
# Google Docs
Google Docs es una aplicación colaborativa para crear muchos tipos de documentos. 
- Escribir el texto de tu documento
- Resumir el contenido de tu documento
- Generar ideas para incluir en el documento
- Sugerir cambios estilísticos para el texto existente
- Corregir la gramática y ortografía

# Gmail
Gmail es una aplicación para enviar y recibir correos electrónicos. Gemini en Gmail puede ayudarte con tareas basadas en la escritura. 
- Redactar correos electrónicos
- Editar contenido dándole un tono más formal, acortando o elaborando el texto existente
puede utilizar la opción Usar tono formal para que el tono del correo electrónico sea más formal. Por último, puede comprobar, editar y perfeccionar el texto para que se ajuste mejor a sus necesidades, además de agregar detalles como la fecha y el lugar de la reunión.

# Google Slides
Google Slides es una aplicación colaborativa para crear presentaciones con diapositivas.
- Generar imágenes únicas para comunicar tus ideas visualmente
- Aplicar estilos visuales específicos a las imágenes generadas

# Google Sheets
Google Sheets es una aplicación colaborativa que te permite organizar y analizar datos en hojas de cálculo.
- Crear hojas de seguimiento para un proyecto
- Analizar datos y obtener insights
- Generar visualizaciones de datos, como tablas o gráficos

# Google Meet
Google Meet es una aplicación de videoconferencia para reuniones virtuales cara a cara.
- Generar subtítulos traducidos entre determinados idiomas durante las reuniones
- Generar imágenes de fondo únicas
- Tomar notas por ti

# Genera insights a partir de múltiples fuentes con NotebookLM
Lo que la diferencia de otras herramientas de IA es que sus respuestas solo se basan en la información de las fuentes que tú le proporciones.
cuando introduces una instrucción, NotebookLM busca en las fuentes que has cargado para construir una respuesta y proporciona citas claras para mostrarte exactamente de dónde procede la información. 

https://notebooklm.google.com/

Ya sea que estés trabajando con informes de proyectos, transcripciones de entrevistas o artículos de investigación, puedes utilizar NotebookLM para convertir una colección de documentos en una base de conocimientos interactiva, ayudándole a trabajar de forma más inteligente con la ayuda de la IA.
